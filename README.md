**OmniVerse Hub** is an expansive, retro-futuristic browser gaming platform and web desktop environment packed with **39+ interactive games**, real-time procedural synthesizers, a cosmetic reward economy, and deep interactive secret ARG lore.

---

## ⚡ Key Highlights

- 🕹️ **39+ Integrated Games**:
  - **Retro Arcade & Action**: Cyber Pac, Mecha Kong, Cyber Hopper (Frogger), Cyber Invaders, Neon Pong Breakout, Viper Drift, Pixel Defense, Cyber Centipede, Neon Timber (Cyber Chopper), Cyber Flappy, Cyber Knife, and more.
  - **Simulation & Tycoon**: Cyber Diner (Food Tycoon), Box Clicker, Quantum Core (Singularity Idle), Mecha Assembly (Cyber Factory), Neon Bio-Lab.
  - **Horror & Story**: Gaby's PlayPlace, Night Shift (CCTV Surveillance Horror), Neon Backrooms: Entity 404 (3D Raycaster), Signal Lost (VHS Terror), Shadow Lurker (Deep Bunker).
  - **Decision & Casino**: Gamblr Decision Suite, ARSpin Wheel, Cyber Crash (Rocket Multiplier), Cyber Mines, Neon Roulette, Cyber 21 (Blackjack).
  - **Puzzle & Strategy**: Cyber 2048: Fusion, Neon Lights Out, Cyber Match 3, Cyber Tetris, Cyber Sweeper, Cyber Wordle, Cyber Simon (Memory Matrix).
- 🖥️ **Multi-Window Web OS**: Run multiple games concurrently in draggable, resizable, stackable floating windows with start menu and clock.
- 🎰 **777 Arcade Challenge Mode**: Random slot-machine game spinner with anti-cheat automatic score verification and coin rewards.
- 🎵 **Procedural Web Audio Synthesizer**: Continuous dynamic chip-tune / synthwave BGM synthesized entirely via the Web Audio API (no external MP3 dependencies).
- 🛍️ **Cyber Shop & Profile System**: Custom animated SVG avatars, animated laser frames, player titles, level progression, and 66 unlockable achievement badges.
- 👁️‍🗨️ **Meta-Horror ARG Storyline (Compy Entity Zero)**: Hidden interactive questlines connecting Gaby's PlayPlace, Cyber Hopper, Night Shift, and Neon Timber with multi-game sabotages and custom glitch events.
